# Abhinav - Amazon SDE Portfolio

A modern, responsive portfolio website built with Next.js 14, TypeScript, and Tailwind CSS for Amazon SDE applicant Abhinav.

## Features

- **Modern Dark Theme** with blue accent (#2563EB)
- **Fully Responsive** design for mobile, tablet, and desktop
- **Optimized Performance** with Next.js Image and lazy loading
- **Accessible** following WCAG 2.1 AA guidelines
- **Contact Form** with Formspree integration
- **Project Showcase** with 3 detailed projects
- **Experience Timeline** highlighting relevant work history
- **Skills Section** with proficiency indicators
- **SEO Optimized** with proper metadata

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **Animations**: React Type Animation
- **Form Handling**: React Hook Form + Formspree
- **Deployment**: Vercel

## Sections

1. **Hero** - Name and title with animated typing effect
2. **About** - Bio, resume download, and LinkedIn link
3. **Skills** - Python, Java, AWS, React with proficiency bars
4. **Projects** - 3 detailed projects with live demos and source code
5. **Experience** - Vertical timeline of work history
6. **Contact** - Form with validation and success/error states

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abhinavpadige4/abhinav-amazon-sde-portfolio.git
   cd abhinav-amazon-sde-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is deployed to Vercel. To deploy your own version:

1. Push the repository to GitHub
2. Import the project on Vercel
3. Vercel will automatically detect the Next.js project and deploy it
4. Configure environment variables if needed (for Formspree)

## Environment Variables

Create a `.env.local` file with:

```
FORMSPREE_ENDPOINT=https://formspree.io/f/your-form-id
```
